# Lab days

A lab day runs from Up to Sleep. The day key is the local date of Up (`YYYY-MM-DD`). Scoring uses that key instead of midnight.

## Stamp rule

A stamp is stored on the profile as `Profile.dayStamps`:

- `id` — string
- `day` — `YYYY-MM-DD`, the local date of `upAt`
- `upAt` — epoch milliseconds when the day started
- `sleepAt` — epoch milliseconds when the day ended, omitted while the day is still open

The field names are `upAt` and `sleepAt`. Rules `wakeTime` and `sleepTime` stay `"HH:mm"` clocks. Defaults stay `06:00` and `22:00`. `sleepTime` does not close a day. Only `sleepAt` does.

`labDayKey(ts, profile)` checks stamps first. A stamp covers `ts` when `upAt <= ts` and either `sleepAt` is missing or `ts < sleepAt`. If more than one stamp covers `ts`, the latest `upAt` wins. The same `upAt` keeps the later stamp in the list. The key is that stamp's `day`.

If Sleep is missing, the day stays open past midnight. An event the next morning still belongs to the Up date, including after `wakeTime`.

`closeOpenDay(profile, atTs)` writes `sleepAt = atTs` on every open stamp that has already started (`upAt <= atTs`). It does not create a stamp, and it does not move a `sleepAt` that is already set. Today and Ledger call it before a new Up so two days are not open together.

## Fallback rule

When no stamp covers `ts`, the day splits at `profile.rules.wakeTime`, default `06:00`, not at `00:00`. If the local time of day is earlier than `wakeTime`, the lab day is the previous calendar date. Otherwise it is the calendar date of `ts`. A blank or invalid `wakeTime` uses `06:00`. Comparison is the local hour and minute against `HH:mm`: `06:00:00` belongs to the new day, `05:59` belongs to the previous one. This path returns a key only. It does not write a stamp.

Examples, with `wakeTime` `06:00`:

- No stamps, 02:00 → the previous calendar date.
- Up Tuesday 10:00, sleep Wednesday 02:40, event Wednesday 01:15 → Tuesday.
- Up Tuesday 10:00, no `sleepAt`, event Wednesday 02:10 → Tuesday. Wednesday 10:00 is still Tuesday while that stamp is open. After `closeOpenDay` at 02:40, Wednesday 10:00 is Wednesday.

## Score and files

`scoreDays` and `scoreToday` group events and carry overflow by the lab day key. Desktop Today lists events with that same key. The phone Ledger scores with that same key (`scoreToday`, `milesToday`).

`dayStamps` round-trips in the desktop lab export and the phone lab JSON. Export version stays 1. An empty stamp list is omitted. On the phone, a file that omits `dayStamps` keeps the stamps already on the device; a file that includes the field replaces them.

The workout event packer does not pack stamps. Packed workout rows still use the calendar date of the event timestamp. Stamps sit on the profile next to `events` and `eventPack`.

## Up, Sleep, and backfill

Desktop Today and the phone Ledger use the same day control. The labels are Up and Sleep.

The selector opens on the lab day that contains now. An open stamp, with no Sleep, stays selected after midnight. Previous and next move one calendar date. A date field jumps to any day, including a past day with no events yet.

Up and Sleep time fields write that day's stamp. Up is a clock time on the lab day's date. Sleep is that clock on the same date when it is after Up, and on the next calendar date when it is not. Clearing Sleep removes `sleepAt` and leaves the day open. Sleep on a day that has no Up uses `rules.wakeTime` as Up so the stamp has a start. The fallback `sleepTime` is not written onto the stamp.

Up and Sleep buttons show only when the selected day is the lab day that contains now. Each button stores `Date.now()`. Up uses the local date of that instant. If that starts a stamp on a day that is not already open, any earlier open stamp is closed at the new Up. A second Up on the same calendar date moves that stamp's Up to now and drops Sleep when Sleep is no longer after Up.

Points from Today and Ledger go on the selected day, with `source` `manual`. A point value of 0 is not stored. Blank Time uses noon on the lab day's date when that noon belongs to the day. If it does not, the point is placed at Up, or at the fallback wake time, so it still scores on the selected day. A Time value uses that clock on the lab day's date, or on the next calendar date when that instant is the one on the lab day. A time that would score on a different day is refused.

The selected day shows its label, cap (`towardCap` / cap and overflow), miles, and that day's events, newest first. Miles stay hidden at 0. An empty current day says "No walks or logs today." Any other selected day says "No walks or logs this day."

Backfill is that same control on a past day. The one-tap buttons stay off. The time fields set Up and Sleep, and Time places the points.

Settings keeps `wakeTime` and `sleepTime` as the fallback clock. `wakeTime` is the split when no stamp covers a time. `sleepTime` does not close a day. Neither field writes a stamp by itself.
